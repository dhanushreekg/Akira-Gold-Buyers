# Akira Gold Buyers

A modern React + Vite website for Akira Gold Buyers, a gold buying business focused on transparent pricing, doorstep service, instant payments, and trust-focused customer experience.

## Overview

This project is a responsive marketing and lead-generation website designed for a gold buying business in Bangalore. It includes home, about, services, FAQ, and contact pages, with a polished UI and conversion-focused inquiry forms.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Radix UI components
- Lucide React icons

## Features

- Responsive landing page for gold buying services
- Dedicated About, Services, FAQ, and Contact pages
- Inquiry/contact form for customer leads
- Testimonials and service highlights
- SEO-friendly metadata and schema markup
- Floating contact action buttons and scroll-to-top navigation
- Modern UI with accessible UI primitives

## Prerequisites

- Node.js 18+
- npm

## Installation

1. Clone the repository:

```bash
git clone https://github.com/dhanushreekg/Akira-Gold-Buyers.git
cd Akira-Gold-Buyers
```

2. Install dependencies:

```bash
npm install
```

## Development

Start the local development server:

```bash
npm run dev
```

The app will run in development mode with Vite. By default, it serves from the `web` directory configured in `vite.config.js`.

## Production Build

Generate the production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Notes

- The site is configured with Vite root pointing to `web/`.
- Styling is managed via Tailwind CSS.
- Several UI elements use Radix UI and custom styling layers for consistency.
